# App Store Release Package

Material for Voicely's first public App Store release (iPhone, iPad, and Mac in one listing). Nothing here submits anything to Apple.

## Files

- `app-store-metadata.md`: listing copy in English and Chinese, keywords, categories, platform requirements, and URLs still to publish.
- `privacy-and-review-notes.md`: App Review notes, App Privacy answer with its reasoning, privacy policy draft, permissions, export compliance, and review risks.
- `screenshot-plan.md`: screenshot sizes, shot list, and captions for iPhone, iPad, and Mac.
- `release-checklist.md`: steps from the pre-release checks through archive, upload, and App Store Connect.
- `widget-shortcuts-roadmap.md`: planning notes for widgets, App Shortcuts, and other system entry points.

`docs/stable-roadmap.md` stays the source of truth for what must be done before the release; the checklist points to it.
